# Prototipos de referencia

Se conservan aquí `generator.py`, `egpsr_commands.py`, `gpsr_commands_v1.py`
y `llm.py`. No forman parte del flujo actual de entrenamiento o servicio HTTP.
Sus dependencias externas, como `robocupathome_generator`, se
mantienen sin adaptación; no son entradas soportadas del paquete `qwen_gpsr`.

El generador del sistema es `qwen_gpsr.generation.generate_dataset`.
